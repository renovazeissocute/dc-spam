How to get your token
✅
Works 100% on iPhone Safari — no Mac or PC needed!
1
Copy the bookmarklet code
Tap the button below to copy the extractor code to your clipboard.
Tap to copy the code
2
Bookmark any page
Open any webpage in Safari (e.g. google.com). Tap Share ▲ → Add Bookmark. Name it DC Token → Save.
3
Edit that bookmark URL
Tap 📘 Bookmarks → find DC Token → swipe left → Edit. Clear the URL field → long-press → Paste. Tap Done.
4
Run it on discord.com/app
Go to discord.com/app in Safari and log in. Tap the address bar → Bookmarks → DC Token. A popup shows your token — tap Copy.
5
Return here & paste
Tap 📋 in the token field above → Verify & Connect.
⚠
Never share your token. It gives full access to your Discord account.
