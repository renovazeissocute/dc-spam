How to get your token
✅
Works 100% on iPhone Safari — no Mac or PC needed!
1
Copy the bookmarklet code
Tap the button below to copy the extractor code to your clipboard.
Tap to copy the code
2
Bookmark any page
Open any webpage in Safari (e.g. google.com).
Tap the Share ▲ button → tap “Add Bookmark”.
Name it DC Token → tap Save.
3
Edit that bookmark’s URL
Tap the 📘 Bookmarks icon → find DC Token → swipe left → tap Edit.
Clear the URL field → long-press → Paste the code you copied in Step 1.
Tap Done to save.
4
Run it on discord.com/app
Go to discord.com/app in Safari and log in.
Tap the address bar → tap Bookmarks → tap DC Token.
A popup shows your token — tap Copy.
5
Return here & paste
Come back to this app → tap 📋 → tap Verify & Connect.
⚠
Never share your token. It gives full access to your Discord account.
